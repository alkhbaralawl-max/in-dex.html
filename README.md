# ركن الغرب — تجهيز نقل التشغيل إلى السيرفر

هذا فرع تطوير منفصل باسم `server-migration`. فرع `main` المنشور لم يتم تعديله.

## الملف المرفوع
- `index.html`: أحدث نسخة واجهة الموقع الحالية.

## لوحة التحكم
لم أضع لوحة التحكم القديمة في المستودع العام؛ لأنها تحتوي مصادقة مشرف من جهة المتصفح وعمليات إدارية مباشرة على قاعدة البيانات. رفعها كما هي سيكشف آلية دخول المشرف ويزيد خطر العبث بأرصدة اللاعبين. سيتم إدراج لوحة التحكم بعد نقل تسجيل الدخول وتعديل الأرصدة والتسويات إلى API خادمي.

## أمان
- لا توجد مفاتيح API خارجية أو كلمات مرور أو مفاتيح Service Account في هذا الفرع.
- وجود Firebase client config في HTML لا يغني عن قواعد Firebase آمنة.
- الواجهة الحالية ما زالت تعتمد على Firebase من المتصفح؛ هذا الفرع نقطة انطلاق فقط، وليس إصدارًا خادميًا آمنًا للنشر.

## الخطوة التالية
بناء Cloudflare Worker وD1، ثم نقل المصادقة والألعاب والتذاكر وتسوية النتائج إلى الخادم، وبعدها ربط الموقع ولوحة التحكم بالـAPI الخادمي.
