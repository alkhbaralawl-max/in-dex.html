# تطبيقات ركن الغرب لنظام Android

هذا المجلد يبني **تطبيقين مستقلين قابلين للتثبيت** من ملفات واجهتي المشروع الحالية:

- `player/`: يضم ملف `index.html` الحالي وكل أصول تثبيت الموقع العام، داخل التطبيق.
- `admin/`: يضم ملف `admin.html` الحالي من فرع `admin-private-domain-fix`، داخل تطبيق منفصل للمشرف.

## طريقة التشغيل

كلا التطبيقين مبنيّان باستخدام Capacitor Android، ويحمّلان الواجهة من الملفات المضمّنة محليًا داخل حزمة APK. لا يوجد `server.url` ولا تحويل إلى Chrome أو رابط الموقع عند التشغيل. الاتصال بالإنترنت مطلوب لتسجيل الدخول والبيانات والألعاب والإدارة لأنها تظل على Supabase.

- معرّف تطبيق اللاعبين: `com.ruknalgharb.player`
- معرّف تطبيق المشرف: `com.ruknalgharb.admin`
- أصل WebView المحلي في Android: `https://localhost`

يسمح كل من `auth-api` و`app-api` بأصل Capacitor المحلي المحدد فقط بالإضافة إلى الأصول السابقة. صلاحيات المشرف ما زالت تتحقق في الخادم، وليس اعتمادًا على إخفاء الواجهة داخل التطبيق.

## بناء APK

يشغّل GitHub Actions ملفي بناء منفصلين ويرفع:

- `Rukn-AlGharb-Players.apk`
- `Rukn-AlGharb-Admin.apk`

هذه نسخ Debug قابلة للتثبيت للاختبار. لم تُنشأ مفاتيح توقيع Release عامة في المستودع؛ يلزم مفتاح توقيع خاص عند إعداد إصدار توزيع دائم وتحديثاته.

لا يغيّر هذا البناء نشر الموقعين أو بيانات Supabase. تغييرات منطق السلسلة تُطبّق على الخادم وقاعدة البيانات بصورة مستقلة.


## تحديثات داخل التطبيق (OTA)

تم تجهيز هيكل تحديثات حيّة منفصل لكل تطبيق باستخدام Capawesome Live Update المتوافق مع Capacitor 8:

- أول إصدار انتقالي من تطبيق اللاعبين وأول إصدار انتقالي من تطبيق المشرف يضمّنان محرك التحديث.
- بعد تثبيت الإصدار الانتقالي، تحديثات HTML وCSS وJavaScript والصور والأصول المتوافقة تُنشر كحزمة ZIP موقّعة، ويظهر للمستخدم تنبيه داخل التطبيق مع زر «تحديث الآن» وشريط تقدم حتى 100%.
- بعد التحقق من SHA-256 وتوقيع RSA، تُجهّز الحزمة وتُطبّق بإعادة تحميل واجهة التطبيق. لا حاجة لتنزيل APK لكل تعديل ويب.
- لكل تطبيق مفتاح توقيع مستقل. المفاتيح الخاصة محفوظة كمتغيرات بيئة سرية على Vercel ولا تدخل في المستودع أو التطبيق؛ التطبيق يحتوي المفتاح العام للتحقق فقط.
- عند فشل تشغيل الحزمة، إعداد مهلة الجاهزية يتيح الرجوع إلى الحزمة الافتراضية. ويُمنع تكرار محاولة الإصدار الذي تم حظره بسبب فشل سابق.
- تعديلات Android الأصلية أو إضافة/ترقية إضافة Capacitor أو تغيير الصلاحيات/الأيقونة ما زالت تحتاج إصدار APK جديدًا.
- تغييرات واجهة اللاعبين على main تُنشر من مسار Vercel. وتغييرات لوحة المشرف على admin-private-domain-fix تُشغّل سير عمل منفصلًا لإعادة نشر حزمة المشرف. مسار بناء APK لا يعمل عند تغييرات صفحات الويب العادية.

مسارات بيانات التحديث:
- https://rukn-algharb-main.vercel.app/ota/player/latest.json
- https://rukn-algharb-main.vercel.app/ota/admin/latest.json

صفحة تنزيل APK العامة تظل للاعبين فقط؛ هذا المسار خاص بحزم تحديث واجهة التطبيقين وليس رابط تنزيل APK للمستخدمين.
