# تطبيقات ركن الغرب لنظام Android

هذا المجلد يبني **تطبيقين مستقلين قابلين للتثبيت** من ملفات واجهتي المشروع الحالية:

- `player/`: يضم ملف `index.html` الحالي وكل أصول تثبيت الموقع العام، داخل التطبيق.
- `admin/`: يضم ملف `admin.html` الحالي من فرع `admin-private-domain-fix`، داخل تطبيق منفصل للمشرف.

## طريقة التشغيل

كلا التطبيقين مبنيّان باستخدام Capacitor Android، ويحمّلان الواجهة من الملفات المضمّنة محليًا داخل حزمة APK. لا يوجد `server.url` ولا تحويل إلى Chrome أو رابط الموقع عند التشغيل. الاتصال بالإنترنت مطلوب لتسجيل الدخول والبيانات والألعاب والإدارة لأنها تظل على Supabase.

- معرّف تطبيق اللاعبين: `com.ruknalgharb.player`
- معرّف تطبيق المشرف: `com.ruknalgharb.admin`
- أصل WebView المحلي في Android: `https://localhost`

يسمح كل من `auth-api` و`app-api` بأصل Capacitor المحلي المحدد فقط بالإضافة إلى الأصول السابقة. صلاحيات المشرف ما زالت تتحقق في الخادم، وليس اعتمادًا على إخفاء الواجهة داخل التطبيق.

## بناء APK

يشغّل GitHub Actions ملفي بناء منفصلين ويرفع:

- `Rukn-AlGharb-Players.apk`
- `Rukn-AlGharb-Admin.apk`

هذه نسخ Debug قابلة للتثبيت للاختبار. لم تُنشأ مفاتيح توقيع Release عامة في المستودع؛ يلزم مفتاح توقيع خاص عند إعداد إصدار توزيع دائم وتحديثاته.

لا يغيّر هذا البناء نشر الموقعين أو بيانات Supabase. تغييرات منطق السلسلة تُطبّق على الخادم وقاعدة البيانات بصورة مستقلة.


## تحديثات داخل التطبيق (OTA)

تم تجهيز محرك التحديث الحي للتطبيقين باستخدام Capawesome Live Update المتوافق مع Capacitor 8:

- الإصدار الانتقالي الأول لكل تطبيق يضمّن محرك التحديث داخل APK. بعد تثبيتهما، تغييرات HTML وCSS وJavaScript والصور المتوافقة تصل من داخل التطبيق من دون تنزيل APK جديد.
- عند وجود إصدار، تظهر شاشة «يتوفر تحديث جديد» وزر «تحديث الآن»؛ يُعرض تقدم التحميل حتى 100%، ثم يُطبّق التحديث ويُعاد فتح الواجهة.
- كل حزمة تُوقّع بمفتاح RSA مستقل عن التطبيق الآخر، ويُتحقق من التوقيع وSHA-256 قبل التطبيق. مفاتيح التوقيع الخاصة محفوظة كمتغيرات Vercel السرية، والمفتاح العام فقط داخل التطبيق.
- تحديث اللاعبين: حزم عامة على مستضيف OTA منفصل، ولا تُنشر على صفحة APK سوى نسخة تطبيق اللاعبين.
- تحديث المشرف: ملف ZIP وبياناته في Supabase Storage خاص (غير عام). نقطة إصدار رابط التحميل تتحقق من جلسة مشرف فعالة، ثم تمنح رابطًا موقّتًا. لا يوجد رابط عام لحزمة المشرف.
- إذا فشل تشغيل حزمة جديدة، يمكن لمحرك التحديث الرجوع إلى الحزمة الافتراضية وحظر إعادة محاولة الحزمة الفاشلة.
- تعديلات Android الأصلية أو إضافة/ترقية إضافة Capacitor أو تغيير الصلاحيات/الأيقونة تتطلب APK جديدًا؛ تعديلات الواجهة المعتادة لا تتطلب ذلك.
- Workflow إنشاء APK صار محصورًا في تغييرات Android الأصلية وملفات إعداد Capacitor والأيقونات؛ تغييرات صفحات الويب وملفات بناء حزم OTA لا تشغّل بناء APK.

مسارات التحديث:
- اللاعبين: `https://rukn-algharb-ota.vercel.app/ota/player/latest.json`
- المشرف: `https://qoeefydvmkdigixsbpuy.supabase.co/functions/v1/ota-api` (لا يعيد رابط الحزمة إلا بعد التحقق من جلسة المشرف).

**حالة النشر:** محرك التحديث وحماية حزمة المشرف موجودان في المشروع، ووظيفتا Supabase `ota-api` و`ota-publish` نشطتان، ومخزن المشرف خاص. يتبقى ربط مستضيف OTA المستقل بمستودع GitHub داخل Vercel حتى يتم النشر تلقائيًا من تغييرات `main`؛ لم أغيّر استضافة الموقع الرئيسي أو أعطّل أي خدمة قائمة.
