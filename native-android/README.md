# ركن الغرب — تطبيقات Android أصلية

هذا المسار يحتوي تطبيقين Android منفصلين مبنيين بواجهات Kotlin وJetpack Compose، ولا يستخدمان WebView أو يفتحان موقعًا داخل التطبيق.

## التطبيقات

- Player: التطبيق المستقل للاعبين، بمعرّف `com.ruknalgharb.player`.
- Admin: تطبيق المشرف المستقل، بمعرّف `com.ruknalgharb.admin`. يتحقق من دور الحساب من الخادم، ويمنع لقطات الشاشة داخل التطبيق.

كلا التطبيقين يتصلان بخدمات Supabase مباشرة عبر HTTPS. تظل بيانات الحسابات والأرصدة والجولات على الخادم وقاعدة البيانات، ولا يوجد تخزين محلي للأرصدة أو نتائج الألعاب.

## البناء

يشغّل GitHub Actions ملف `.github/workflows/build-native-android.yml` وينتج ملفي Debug APK منفصلين:
- `Rukn-AlGharb-Players.apk`
- `Rukn-AlGharb-Admin.apk`

هذه ملفات اختبار وتثبيت مباشر، وليست ملفات إصدار متجر موقّعة بمفتاح إنتاج.

## متطلبات إكمال التكامل

- مصدر `app-api` في هذا الفرع يتضمن دعمًا من جهة الخادم للنرد والأوراق. هذا التعديل موجود في الفرع فقط ولم يتم نشره على Supabase.
- يجب مراجعة إعدادات Supabase والإصدارات المنشورة من `auth-api` و`app-api` قبل اعتماد ملفي APK. لا تُعتبر واجهات الألعاب مكتملة حتى تعمل على خدمة محدثة وتُختبر جولات فعلية برصيد افتراضي.
- إزالة قسم المباريات والتوقعات من الواجهات لا تعني حذف سجلاته القديمة من قاعدة البيانات. هذا الفرع لا ينفذ حذفًا لتلك السجلات.
- لم يتم إيقاف الموقعين القديمين أو تغيير إعدادات الإنتاج بهذا العمل.
